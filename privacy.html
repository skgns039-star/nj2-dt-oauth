Privacy Policy / 개인정보처리방침

Effective 2026-09-29

Scope

This policy covers the private tool "NJ2 DT Analytics MCP", used only by its owner on the owner's own computer.

Data accessed

  • Google Analytics 4 report data (scope analytics.readonly) for properties the owner already has access to. Read-only.
  • Gmail send permission (scope gmail.send) to send report emails to the owner's own address. The tool does not read, modify or delete any email.

Use and storage

Data is processed locally on the owner's computer to produce analysis reports. OAuth tokens are stored locally with owner-only file permissions. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions).
